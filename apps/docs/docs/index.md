文档使用 `dumi-theme-mobile` 提供移动端文档布局，使用 `react-native-web` 将组件 fixture 渲染为可交互 H5 demo。组件文档和 fixture 与源码放在同一个目录，统一使用 dumi 标准写法：

```md
<code src="./__fixtures__/basic.tsx"></code>
```

当前文档只提供 Web 预览，不接入 Expo Snack。依赖 Native Module、Fabric 原生组件或 HarmonyOS 专属能力的行为，仍需在 Native Runtime 中验证。
