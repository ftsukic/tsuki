# 安装

```bash
yarn add @ftsukic/react-native-ui
```

当前已提供 Theme/Provider、Button、Cell、Cell.Group、TextInput、Icon 和 LoadingIcon。

目标兼容范围：

| React     | React Native |
| --------- | ------------ |
| `19.1.1+` | `0.82.0+`    |

启动本地 H5 文档：

```bash
yarn docs:dev
```

文档页面中的 demo 使用 `react-native-web` 渲染；需要 Native Module、Fabric 或平台专属能力时，请在对应 Native Runtime 中验证。
