# @ftsukic/react-native-ui

基础 React Native UI 组件库。

当前版本 `0.0.1` 仅提供包结构和构建入口，具体组件 API 将在后续版本加入。

```bash
yarn add @ftsukic/react-native-ui
```

该包目标面向 React Native `0.82.1+` 和 React `19.1.1+`。

Harmony 使用基线为 React Native `0.82.1`。组件库本身不依赖 HarmonyOS、Expo 或其他 Native Module，Harmony 宿主应用需要自行提供对应的 RNOH 运行环境。
